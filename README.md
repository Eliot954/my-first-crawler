# 招聘数据采集与分析工具

为AI招聘/简历分析产品提供数据支持的项目。

## 项目背景
为了开发AI简历分析等产品，需要真实的市场招聘数据。本项目实现了数据抓取、清洗和可视化。

## 核心功能与贡献
- 使用requests抓取招聘数据
- pandas进行数据清洗并进行统计分析
- 生成薪资、技能、城市分布等可视化图表
- 输出CSV/Excel格式数据，可直接用AI项目

## 产品思考
- 此项目为后续AI招聘产品打下数据基础，考虑了数据合规问题。

## 文件说明
- crawler.py：主程序
- analysis.xlsx / data_cleaned.json：分析结果
- recruitment_analysis.png：可视化报告

## 招聘数据初步分析
已完成模拟招聘数据的抓取、清洗、统计与可视化。

**完成日期**：2026年3月  
**技术栈**：Python、requests、pandas、matplotlib、seaborn
