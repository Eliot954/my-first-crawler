# 我的第一个爬虫升级项目

## 项目简介
使用 `requests` 从公开 API 抓取数据，结合 `pandas` 进行数据清洗和统计分析，并使用 `matplotlib` + `seaborn` 生成可视化图表。

这是一个从“能跑通爬虫”到“完成数据分析”的完整练习项目。

## 主要功能
- 请求公开 API 并生成模拟招聘数据（城市、公司、薪资、岗位标题）
- 数据清洗：去重、填充空值
- 统计分析：
  - 整体平均薪资 & Python岗位平均薪资
  - 城市分布 Top 5
  - 公司岗位数量 Top 5
  - 最高/最低薪资
- 可视化图表（4 张）：
  - 薪资分布直方图
  - 城市岗位分布柱状图
  - Python vs 其他岗位薪资对比
  - 各城市薪资箱线图

## 文件说明
- `crawler.py`：主程序（抓取 + 分析 + 可视化）
- `analysis.xlsx`：清洗后的招聘数据（推荐用 Excel 打开）
- `recruitment_analysis.png`：可视化分析报告
- `data_cleaned.json`：JSON 格式备份
